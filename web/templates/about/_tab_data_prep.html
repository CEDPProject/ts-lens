Upload a single CSV or a folder in Data Management → Upload. A folder can keep each file as its own source (individual) or merge all files into one series in time order (merge). Encoding and delimiter are detected automatically and can be overridden.

Duplicate timestamps, AI metadata, deletion — When a timestamp appears more than once, choose: reject, keep first, keep last, average, or shift; if every timestamp appears exactly k times, the app reports that k regional files were likely merged. The switch at the top of the Upload tab lets a connected external LLM (Anthropic Claude or OpenAI-compatible, set up by an admin under Model Connection) fill dataset key, name, description, location, facility, capacity, interval, characteristics, tags and column metadata; it is off by default, remembers the last choice, and marks AI-filled fields with a red border for review. Deleting a dataset in the Datasets tab also removes its preprocessing results, labels, basket, presets, cache and files after a DB backup. Public examples in data/wind_energy/ include Elia (Belgium) wind generation and forecasts 2015–2026 as five regional hourly CSVs, Sangmyeong wind farm and the Haengwon met mast.

Usage Scenarios

Common situations during data preparation and how to handle them.

1Choosing a Data Format
Researcher
"I have one year of continuous data, but also data split into many short CSV files, like motor run logs. Can I analyze both?"
Both data formats are supported:
  • Continuous time series: one long CSV — sliding window search, split by time unit
  • Segment collection: several CSVs in a folder — compared with DTW even at different lengths, concatenated for continuous exploration when needed
Auto-detect encoding, delimiter and index · Column metadata (unit, min, max) entered or AI-estimated · Sampling interval computed automatically
2Quality Diagnosis
Data Analyst
"This is a new dataset. Before anything else I want to know how many values are missing and how severe the outliers are."
Data Quality Diagnosis
Data quality is diagnosed automatically before preprocessing:
  • Sampling interval: auto-detected (1h, 15min, 1min, etc.)
  • Time gaps: number of missing stretches from sensor downtime and the missing points
  • Outliers (IQR): count and ratio of statistically extreme values
  • NaN values: count of missing values and ratio to the total
Read-only diagnosis · Original data unchanged · Independent analysis per column
3Data Preprocessing
Data Engineer
"There are quite a few sensor gaps and outliers, so running it on the raw data would likely produce unreliable results."
The preprocessing pipeline runs in 3 stages:
  1. Extreme value handling: Choose value range limiting (column min/max) or outlier clamping (IQR, Percentile, Sigma)
  2. Time gap filling: Insert NaN at timestamps missing due to sensor downtime
  3. NaN imputation: Choose from 8 methods — Linear, Cubic, Smoothing spline, Nearest, Zero fill, Forward fill, Adaptive, MOMENT (FM-based context restoration)
Original preserved · 3-stage pipeline · Before/after comparison charts · Revert anytime
4FFT Periodicity Analysis
Energy Analyst
"This is solar generation data. I am not sure whether daily or weekly splitting is right, so I want to check the periodicity first."
FFT Periodicity Analysis
FFT (fast Fourier transform) reveals hidden periodicity in the data:
  • Main peak detection: the strongest periodic pattern is identified automatically
  • Split unit suggestion: 24h peak → daily split, 168h peak → weekly split
  • Multiple cycles: daily, weekly and annual patterns seen at once
Spectrum visualization · Automatic peak detection · Split unit suggestion
5Time Unit Split
Facility Manager
"Sometimes I want to analyze by week, sometimes by hour — I need to split the data into different time units depending on the purpose."
Time Unit Selection (6 types)
Select the desired unit from hour · 6hour · day · week · month · year, and the segment length is automatically calculated based on the data's sampling interval.
  • 6 hours: Separate AM/PM/evening/night patterns
  • 1 day: Daily profile comparison — ideal for solar generation patterns
  • 1 week: Weekly trend analysis — distinguish weekday/weekend patterns
6 time units · Auto-detect sampling interval · Different patterns per unit · Instant switching
6Segment Concatenation (Concat)
Process Engineer
"From the daily segments I want to pick three specific days, join them, and search for patterns across the whole result."
Segment Concatenation
Select several segments and join them into one continuous series:
  • Selective concat: join only the segments you choose
  • Sliding window: search for patterns across the joined series
  • Re-split: split the joined series again into another time unit
Multi-select · Order preserved · Re-split after concat · Full-range search
