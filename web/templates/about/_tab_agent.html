AI Agent Roadmap (Planned)

The current system provides powerful manual tools for time-series pattern discovery. Several LLM-assisted features already run: segment description (ChatTS-14B), text-to-waveform generation, and AI metadata inference that fills dataset and column metadata on upload. External LLMs can be enabled per task in the Model Connection tab. The next evolution is autonomous AI agents that can explore, interpret, and label patterns with minimal human intervention — while keeping the human in the loop for validation and refinement.

Proposed Architecture

Four specialized agents collaborate through a shared message bus, each with access to the existing API as tools.

Candidate Use Cases

1. Autonomous Pattern Discovery

The agent automatically scans the entire dataset: clusters segments, profiles all columns, identifies the most discriminative variables, and generates a structured pattern catalog — all without user input.

Tools used: cluster() → cross_column_profile() → describe() → label()

2. Natural Language Q&A

Ask questions in plain language: "When does power output drop suddenly?" The agent interprets the query, selects appropriate search tools (preset match, text-to-shape, or DTW), executes the search, and returns contextualized answers with evidence.

Tools used: interpret_query() → search() → describe() → summarize()

3. Automated Report Generation

Generate a comprehensive analysis report for a dataset: data quality summary, dominant pattern types, anomaly counts, cross-column correlations, and recommended labels. Exportable as PDF or structured JSON.

Tools used: diagnose() → cluster() → profile() → describe_all() → export_report()

4. Cross-Domain Transfer

Apply a pattern library learned from one domain (e.g., solar irradiance) to a different domain (e.g., wind power). The agent adapts shape templates, adjusts thresholds, and suggests domain-specific label mappings.

Tools used: load_library() → adapt_shapes() → search() → validate()

5. Time-Series LM Interpretation

The agent passes the raw series to a time-series language model (ChatTS-14B, already used for descriptions) and merges its narrative with app-computed statistics, so shapes and events are described in words while numbers stay exact.

Tools used: render_chart() → vlm_analyze() → merge_with_stats() → describe()

6. Active Learning Loop

The agent proposes labels for ambiguous segments and asks the human to confirm or correct. Each correction refines the pattern library, improving future suggestions. Focuses annotation effort on the most uncertain or impactful samples.

Tools used: select_uncertain() → suggest_label() → human_review() → update_library()

Implementation Patterns

PatternDescriptionBest For
Tool-Using Agent LLM decides which API to call based on user query. Each API is registered as a "tool" with schema description. Natural language Q&A, single-step tasks
ReAct (Reason + Act) Think → Act → Observe loop. Agent reasons about what to do next, executes a tool, observes the result, and iterates. Multi-step exploration, autonomous discovery
Multi-Agent Specialized agents (Curator, Interpreter, Retriever, Labeler) pass messages via orchestrator. Each agent has its own tools and context. Complex pipelines, parallel processing
Human-in-the-Loop Agent pauses at decision points to request human validation. Feedback is incorporated into subsequent iterations. Labeling, quality assurance, ambiguous cases
