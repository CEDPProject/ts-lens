TS-Lens는 업로드 → 전처리 → 탐색(검색 · 군집화) → 해석 → 라벨링을 하나의 작업 공간에서 연결하는 웹 기반 시계열 패턴 발견 도구입니다.

TS-Lens 핵심 흐름
사용자는 원하는 패턴을 자연어, 스케치, 예시 구간, 프리셋, 클러스터 대표 형태로 표현합니다. TS-Lens는 이를 검사 가능한 파형 질의로 만들거나 실제 구간과 비교하여 유사 interval을 찾고, 선택된 결과를 자연어 설명, 라벨 바스켓, 커스텀 프리셋으로 이어줍니다.
논문 관점: Describe → Generate → Search → Explain → Curate. 새로운 예측 모델이 아니라, zero-shot 시계열 패턴 탐색을 위한 다중 모달 인터페이스입니다.
뷰 적응형 쿼리 모드
시스템이 데이터 뷰에 따라 사용 가능한 검색 모드를 자동으로 조정합니다:
  • Continuous 뷰: Select (차트 드래그), Sketch (프리핸드 스케치), Text (LLM) — 전체 타임라인에서 슬라이딩 윈도우 검색
  • Segment 뷰: Sample (카드 클릭), Sketch (프리핸드 스케치), Preset (7종 내장 + 커스텀), Cluster (Fast/Shape/Semantic AI), Text (LLM)
이러한 명확한 구분은 각 모드가 혼란 없이 적절한 데이터 구조에서 작동하도록 보장합니다.

데이터 관리

데이터 관리 페이지는 데이터 목록·데이터 업로드·모델 연결 세 탭으로 나뉩니다. 업로드는 파일 1개 또는 폴더(파일마다 개별 소스, 또는 시간순으로 하나로 합치기)를 받고, 인코딩·구분자를 자동 감지하며 같은 시각이 겹칠 때의 처리(저장 안 함·첫 값·마지막 값·평균·밀기)를 고릅니다. 모든 시각이 k번씩 나오면 지역별 파일 k개를 합친 데이터라고 알려줍니다. 데이터셋을 지우면 연결된 전처리 결과·라벨·바스켓·프리셋·캐시·파일이 함께 지워지고, 지우기 전에 DB 백업을 만듭니다. 함께 제공하는 공개 데이터로 Elia(벨기에 송전망 운영사)의 2015~2026년 풍력 발전량·예측을 지역별 시간 단위 CSV 5개로 정리한 것, 상명풍력, 행원 기상탑 데이터가 있습니다.

✨

AI 메타 추정

관리자가 모델 연결 탭에서 외부 LLM(Anthropic Claude 또는 OpenAI 호환 서버)을 연결하면, 업로드 탭 맨 위 스위치로 업로드마다 AI 메타 추정을 켤 수 있습니다(기본 꺼짐, 마지막 선택 기억). 켜면 데이터셋 키·이름·설명·위치·시설·용량·측정 간격·특성·태그와 컬럼 라벨·단위·설명·최소·최대를 채우고, AI가 채운 칸은 붉은 테두리로 표시하며 사용자가 고치면 표시가 사라집니다. 모든 메타 칸에는 ⓘ 설명이 있고, 컬럼 최소·최대는 물리적으로 가능한 범위로서 전처리에서 범위 밖 값을 걸러내는 데 쓰입니다. API 키는 서버 파일에만 저장되고 화면에는 끝 4자리만 보이며, 사용 비용을 추정해 월 $10에서 경고하고 $100에서 막습니다(설정 가능).

⚿

로그인과 모델

로그인은 서버의 config/local/users.yaml 에 계정이 있을 때만 켜집니다. 역할은 관리자와 일반 사용자 두 가지이며, 데이터 업로드와 모델 연결 탭은 관리자만 씁니다. 계정은 화면에서 만들지 않고 관리자가 tools/set_password.py 로 등록합니다. 구간 설명의 기본 모델은 ByteDance Research의 ChatTS-14B로, 별도 서버에서 GPU를 함께 쓰며 8bit로 돌고 요청이 올 때만 올렸다가 5분 동안 쓰지 않으면 내립니다. 외부 LLM도 설명·생성 모델로 고를 수 있습니다.

4개의 전문 에이전트가 각자의 역할을 수행합니다. 에이전트 간 연결은 Flask 라우트를 통해 이루어지며, 사용자가 직접 워크플로우 흐름을 제어합니다.

데이터 큐레이터

데이터 큐레이터

원시 데이터를 정제하고 구조를 분석하여 탐색 준비를 합니다.

  • 전처리 파이프라인 (극단값, 갭, 보간/복원 incl. MOMENT FM)
  • 데이터 품질 진단 (NaN, 범위, 이상치)
  • FFT 주기성 분석
  • 샘플링 간격 감지 / 세그먼트 분할
원시 CSV → 정제 데이터 (DB)

인터프리터

인터프리터 (ChatTS · LLM)

자연어와 시계열 형태 간 양방향 변환을 수행합니다. 도메인 메타데이터를 인식합니다.

  • 순방향: 텍스트 → 형태 (NL-to-Shape)
  • 역방향: 형태 → 텍스트 (구간 설명)
  • 컬럼별 독립 형태 생성 (메타데이터 인식)
  • 설명: ChatTS-14B (별도 GPU 서버, 요청 때만 적재)
  • 생성: 규칙 선처리 + 로컬 모델 또는 외부 LLM (Claude · OpenAI 호환)
자연어 / 세그먼트 값 ↔ 형태 / 설명

검색기

검색기

쿼리 형태와 데이터 세그먼트를 수학적으로 비교하여 유사한 구간을 찾습니다.

  • 슬라이딩 윈도우 / 세그먼트 / 프리셋 자동 분류
  • 4가지 거리 함수 (Euclidean / DTW / Cosine / Shape)
  • Z-점수 정규화 + NaN 처리
  • 다중 컬럼 검색
쿼리 형태 + 데이터 → 순위 결과

라벨러

  • 정제: 인스턴스 평균 → 개선된 형태
  • 패턴 라이브러리 CRUD

핵심 차별점
  • 생성 기반 자연어 질의: 자연어를 불투명한 벡터에 숨기지 않고 눈으로 확인할 수 있는 파형으로 변환해, 검색 결과 및 생성 모델 출처와 함께 보여 줍니다.
  • 양방향 텍스트↔시계열: 텍스트→시계열(질의 생성)과 시계열→텍스트(구간 설명)를 하나의 작업 공간에서 함께 제공합니다.
  • 사람이 참여하는 큐레이션: 유용한 결과는 라벨 바구니에 모으고, 검토를 거친 질의 형태나 군집 대표(medoid)는 사용자 프리셋으로 저장해 일회성 조회에 그치지 않고 다시 사용할 수 있습니다.
