Usage Scenarios

Scenario 1: Find Clear-Sky Days (Preset Mode)

  1. Load solar dataset in Finder page
  2. "Segment View" → Time Unit "1day" → split into 365 daily segments
  3. Preset mode → click "bell" preset → "Search"
  4. → 168 days found matching the bell-shaped pattern

Scenario 2: Natural Language Search (Text Mode)

  1. Text mode → enter "asymmetric bell shape, rises quickly in morning, peaks at noon, falls slowly"
  2. LLM generates synthetic time series → preview displayed
  3. "Search" → 34 asymmetric clear-day patterns discovered

Scenario 3: Auto-Discover Patterns (Cluster Mode)

  1. Cluster mode → K-Means Auto-K → "Search"
  2. System selects optimal K=5 → 5 clusters found
  3. Clear(142), Partial(98), Overcast(76), Dropout(34), Anomaly(15)

Key Terms

Core concepts and terminology used in TS Pattern Finder.

Data Structures

TermDescription
Single DatasetOne continuous time series. Supports sliding window search in Continuous view.
Collection DatasetA set of segments with identical structure. Displayed as cards in Segment view.
SegmentA time-series slice covering a specific time range. Split by day, week, etc.

Search & Comparison

TermDescription
QueryThe reference pattern for search. Generated via Select/Sketch/Sample/Preset/Text/Cluster modes.
Sliding WindowA fixed-length window that moves across continuous data, comparing similarity at every position.
QBE (Query-by-Example)Search by example. Click a segment card to use its waveform as the query.
Euclidean DistanceSquare root of the mean squared point-wise differences (RMSD).
DTWSimilarity measure allowing time-axis warping. Can compare patterns with different lengths.
Z-scoreNormalize to mean 0, std 1. Compares shape only, ignoring absolute values.

Clustering & Analysis

TermDescription
K-Means (Fast)Distance-based clustering. Fast and scalable, best for general use.
k-Shape (Shape)Shape-Based Distance (SBD). Scale/shift invariant, designed for time series.
MOMENT (Semantic AI)Foundation model-based. Naturally supports multivariate joint clustering.
Centroid (Medoid)The actual member segment closest to the center, not the mean.

LLM & Pattern Generation

TermDescription
NL-to-Shape (DGS)Natural language → rule pre-pass or LLM (local/external) → synthetic time-series shape. Describe-Generate-Search pipeline.
Shape-to-TextSegment → ChatTS-14B (or external LLM) narrative + app-computed numbers → natural language description.
Domain-AwareUses column metadata (units, ranges) to generate physically plausible shapes.

UI & Modes

TermDescription
Continuous ViewContinuous time-series view. Select, Sketch, and Text modes available.
Segment ViewSegment view. Sample/Sketch/Preset/Cluster/Text modes available.
View-AdaptiveFeatures automatically adjust based on the current data view.
Label BasketCollection area for accepted segments. Has Draft and Confirmed stages.
