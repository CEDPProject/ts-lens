AI Agent 로드맵 (계획중)

현재 시스템은 시계열 패턴 탐색을 위한 강력한 수동 도구를 제공합니다. LLM 보조 기능 일부는 이미 동작합니다 — 구간 설명(ChatTS-14B), 문장→파형 생성, 업로드 때 데이터셋·컬럼 메타를 채우는 AI 메타 추정입니다. 외부 LLM은 모델 연결 탭에서 작업별로 켤 수 있습니다. 다음 단계는 자율 AI 에이전트가 최소한의 인간 개입으로 패턴을 탐색, 해석, 라벨링하되, 검증과 개선을 위해 인간을 루프에 유지하는 것입니다.

제안 아키텍처

4개의 전문 에이전트가 공유 메시지 버스를 통해 협업하며, 각각 기존 API를 도구로 사용합니다.

후보 유즈케이스

1. 자율 패턴 발견

에이전트가 전체 데이터셋을 자동 스캔: 세그먼트 클러스터링, 전 컬럼 프로파일링, 가장 변별력 있는 변수 식별, 구조화된 패턴 카탈로그 생성 — 사용자 입력 없이 모두 자동 수행.

사용 도구: cluster() → cross_column_profile() → describe() → label()

2. 자연어 질의응답

자연어로 질문: "발전량이 급격히 떨어지는 시점은 언제인가요?" 에이전트가 질의를 해석하고, 적절한 검색 도구(프리셋 매칭, 텍스트-투-셰이프, DTW)를 선택하여 실행한 뒤, 근거와 함께 맥락화된 답변을 반환합니다.

사용 도구: interpret_query() → search() → describe() → summarize()

3. 자동 보고서 생성

데이터셋에 대한 종합 분석 보고서 자동 생성: 데이터 품질 요약, 지배적 패턴 유형, 이상치 건수, 교차 컬럼 상관관계, 권장 라벨. PDF 또는 구조화된 JSON으로 내보내기 가능.

사용 도구: diagnose() → cluster() → profile() → describe_all() → export_report()

4. 도메인 간 전이

한 도메인(예: 태양광 일사량)에서 학습한 패턴 라이브러리를 다른 도메인(예: 풍력 발전)에 적용. 에이전트가 형상 템플릿을 적응시키고, 임계값을 조정하며, 도메인별 라벨 매핑을 제안합니다.

사용 도구: load_library() → adapt_shapes() → search() → validate()

5. 시계열 언어 모델 해석

에이전트가 시계열을 시계열 언어 모델(설명 기능에 쓰는 ChatTS-14B)에 그대로 넣고, 모델의 서술과 앱이 계산한 통계를 합칩니다. 모양·사건은 말로, 숫자는 계산값으로 남깁니다.

사용 도구: render_chart() → vlm_analyze() → merge_with_stats() → describe()

6. 능동 학습 루프

에이전트가 모호한 세그먼트에 대한 라벨을 제안하고 사용자에게 확인 또는 수정을 요청. 각 수정은 패턴 라이브러리를 개선하여 향후 제안의 정확도를 향상시킵니다. 가장 불확실하거나 영향력 있는 샘플에 어노테이션 노력을 집중.

사용 도구: select_uncertain() → suggest_label() → human_review() → update_library()

구현 패턴

패턴설명적합한 용도
Tool-Using Agent LLM이 사용자 질의에 따라 호출할 API를 결정. 각 API는 스키마 설명과 함께 "도구"로 등록. 자연어 질의응답, 단일 단계 작업
ReAct (추론 + 행동) Think → Act → Observe 루프. 에이전트가 다음 행동을 추론하고, 도구를 실행하고, 결과를 관찰한 후 반복. 다단계 탐색, 자율 발견
Multi-Agent 전문화된 에이전트(Curator, Interpreter, Retriever, Labeler)가 오케스트레이터를 통해 메시지 전달. 각 에이전트는 자체 도구와 컨텍스트를 보유. 복잡한 파이프라인, 병렬 처리
Human-in-the-Loop 에이전트가 의사결정 지점에서 일시 정지하여 인간의 검증을 요청. 피드백은 후속 반복에 반영. 라벨링, 품질 보증, 모호한 사례
