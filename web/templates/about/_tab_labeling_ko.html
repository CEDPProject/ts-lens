라벨링 & 패턴 라이브러리

Labeler 검색 결과를 검토하고 수락/거절로 패턴 라이브러리를 점진적으로 쌓습니다. 확정된 패턴은 쿼리 정제에 쓰여 검색 품질이 올라갑니다.

검색 결과에서 수락한 세그먼트를 모아 관리합니다. 담을 당시의 싱글·멀티 컬럼 파형과 종합 유사도, 거리 방법, 정규화 설정을 함께 보존하며, 컬럼 선택기에서 원본의 다른 컬럼도 검토할 수 있습니다. 카드 미리보기는 화면에 가까워질 때 극값을 보존한 축약 데이터로 불러오고, CSV 내보내기는 정확한 전체 행을 유지합니다.

Draft (임시)
검토 대기 항목
  • 검색 결과에서 Accept(수락)를 누르면 추가
  • 개별 삭제 또는 일괄 삭제 가능
  • 검토 후 Confirm All(모두 확정)로 확정
Confirmed (확정)
최종 확정된 패턴
  • Draft에서 확정된 항목이 이동
  • 잘못 확정한 항목은 삭제 가능
  • 평균 형태로 쿼리 자동 정제

일괄 작업

Select All(모두 선택) — Draft 또는 Confirmed 구역의 모든 항목 선택
Delete Selected(선택 삭제) — 선택한 항목을 한 번에 삭제
Confirm All — Draft 전체를 Confirmed로 이동

클러스터 중심을 커스텀 프리셋으로 저장

클러스터 분석(Fast/Shape/Semantic AI)을 돌린 뒤 각 클러스터의 중심(Medoid — 중심에 가장 가까운 실제 멤버)을 패턴 라이브러리에 커스텀 프리셋으로 저장할 수 있습니다. 저장한 형태는 Preset 모드에서 직접 추가한 기본 프리셋과 함께 표시되며, 맥락이 맞도록 데이터셋별로 보관됩니다.

워크플로우
  1. 세그먼트 뷰로 전환 → Cluster 모드 실행(Fast/Shape/Semantic AI)
  2. 클러스터 결과 검토 — 그룹마다 Medoid 형태와 멤버 세그먼트 표시
  3. 클러스터 카드의 버튼 클릭 → 패턴 이름 입력(예: "Morning Double Peak")
  4. 중심이 패턴 라이브러리에 저장 → Preset 모드에서 커스텀 프리셋으로 사용
  5. 커스텀 프리셋은 × 버튼으로 삭제(내장 프리셋은 삭제 불가)
장점
데이터셋별 보관: 프리셋은 데이터셋별로 저장 — 태양광 패턴은 태양광 데이터에서만 보입니다. 라이브러리는 서버에 있고 모든 계정이 공유합니다
Medoid 기반: 평균이 아니라 중심에 가장 가까운 실제 멤버 세그먼트를 사용 — 이상치에 강합니다
반복 탐색: 클러스터 → 저장 → 검색 → 정제 → 더 많은 맥락으로 다시 클러스터

컬럼 간 상관 인사이트

클러스터링 중에 생성되는 컬럼 패턴 상관 맵은 측정 변수들이 어떻게 함께 변하는지 보여 줍니다. 각 셀은 실제 평균 형태의 SVG 스파크라인과 통계적 신뢰도를 나타내는 일관성 배지를 담습니다.

일관성 등급
Strong (>=85%): 거의 모든 멤버가 같은 형태 — 신뢰할 수 있는 패턴
Moderate (>=70%): 다수가 같은 형태 — 대체로 신뢰 가능
Weak (>=55%): 편차 있음 — 주의해서 해석
Noisy (<55%): 편차 큼 — 평균 형태가 대표성 없음

라이브러리 활용

새 데이터에 적용: 같은 데이터셋에 새 구간·새 기간이 들어오면 저장된 패턴으로 바로 검색
팀 공유: 패턴 정의가 라이브러리에 보존되어 협업 가능
CSV 내보내기: 라벨링 결과를 CSV로 내려받기

라벨링 기능을 활용한 실제 워크플로우 사례.

1패턴 라이브러리 구축
데이터 분석가
"검색 결과에서 필요한 패턴만 골라 패턴 라이브러리에 저장하고, 나중에 다시 쓰고 싶다."
라벨링 루프
  1. 검색: Text/Preset/Sample/Cluster 모드로 패턴 검색
  2. 판정: 정확한 결과는 Accept, 틀린 결과는 Reject(거절)
  3. 확인: Draft에서 검토 후 Confirm All로 확정
  4. 정제: 확정된 세그먼트의 평균 형태로 쿼리 개선
  5. 반복: 정제된 쿼리로 재검색 → 더 정확한 결과 → 라이브러리 누적
반복: 검색 → 선택 → 저장 · 패턴별 인스턴스 관리 · 라벨링 결과 CSV 내보내기
2클러스터로 프리셋 만들기
연구원
"클러스터링으로 발견한 패턴을 저장해 두고, 나중에 새 데이터에서 같은 패턴을 빨리 찾고 싶다."
커스텀 프리셋
  1. 세그먼트 뷰 → Cluster 모드 실행(Fast/Shape/Semantic AI)
  2. 클러스터 결과 검토 — 그룹별 Medoid 형태와 멤버 세그먼트 확인
  3. 클러스터 카드의 버튼 클릭 → 패턴 이름 입력(예: "Morning Double Peak")
  4. Preset 모드에 보라색으로 표시되어 재사용
데이터셋별 저장 · Medoid 기반(이상치에 강함) · 클러스터 → 저장 → 검색 → 정제 반복
3신규 데이터 분류
운영 엔지니어
"전에 만든 패턴 라이브러리로 같은 데이터셋에 들어온 새 데이터를 빨리 분류하고 싶다."
Preset 모드
  1. 같은 데이터셋의 새 구간 로드 → 세그먼트 뷰로 전환
  2. Preset 모드에서 라이브러리에 저장된 패턴 선택
  3. "전체 분류" 버튼으로 모든 세그먼트 자동 분류
  4. 분류 결과 검토, 필요하면 추가 라벨링
저장된 패턴 재사용 · 전체 분류 자동화 · 결과 내보내기
4팀 협업
연구팀 리더
"팀원들이 발견한 패턴을 공유하고, 새로 합류한 팀원도 기존 패턴 정의를 쓸 수 있으면 좋겠다."
패턴 라이브러리

패턴 라이브러리는 데이터셋별로 서버에 저장되어 모든 계정이 같이 봅니다. 팀원이 확정한 패턴은 라이브러리에 쌓이고, 새 팀원도 같은 데이터셋을 열면 기존 패턴 정의를 쓸 수 있습니다.
