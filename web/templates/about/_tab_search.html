Common settings such as comparison method, result filter and missing-value handling are configured once under "Advanced Settings".

Generation model and external LLM — Text mode first applies a rule-based pre-pass that turns simple phrases directly into waveforms; other requests go to a local model or an external LLM (Anthropic Claude or OpenAI-compatible). If the user explicitly picks an external LLM, the rule pre-pass is skipped. Administrators connect external LLMs under Data Management → Model Connection; the API key is stored only in a server file and shown as its last four characters. Each connection can be enabled per task (text→series, series→text, AI metadata inference); token usage is logged with a monthly warning at $10 and a limit at $100 (configurable).

Search Modes

1

Continuous Sliding Window

A fixed-length window slides one step at a time over a long series, comparing each position with the query.

To find every position where a pattern repeats in a continuous series
2

Segment-to-Segment Comparison

Pre-divided segments (Collection) are compared directly with the query.

To rank similarity between daily or run-level profiles
3

Continuous → Split Comparison

A continuous series is split into fixed-length chunks (daily, weekly, etc.) and each chunk is compared with the query.

To classify quickly by calendar unit

Options that control the quality of comparison results.

Z-score Normalization

Transforms each segment with (value - mean) / std_dev. Removes absolute magnitude and compares curve shape only.

Z-score OFF: a winter 50 kW bell and a summer 100 kW bell are classified as "different patterns"
Z-score ON: both are the same bell curve → matched as the same pattern

Multi-Column Simultaneous Search

When several columns are selected, the per-column distances are equally averaged into an overall similarity.

Result Filtering

Two filter modes narrow down results when there are too many.

Top-K: show only the N most similar results (5-500, default 20)
Similarity threshold: show only results above a threshold such as 70% — filtering by quality, not quantity

Calendar Alignment

In split comparison mode, segments are aligned automatically to calendar boundaries (midnight, month start, Monday).

6 hours: 00:00, 06:00, 12:00, 18:00 boundaries — distinguish AM/PM patterns
Daily: starts at 00:00 each day — daily profile comparison
Weekly: starts every Monday — weekly trend comparison

NaN Handling (During Comparison)

Select how missing values encountered during comparison are handled.

Interpolation (default): fill NaN with the selected method (linear, cubic, MOMENT FM, etc.) and compare
Skip: if even one NaN is present, the segment is excluded from comparison

Export Results

Search results can be downloaded as CSV for further analysis.

Output format: rank, start_idx, end_idx, length, similarity, distance

Bidirectional conversion — not only Text→TS (search) but also TS→Text (interpretation).

Bidirectional Text ↔ TS Conversion
Search (Text→TS) and interpretation (TS→Text) in one interface
Forward
Text → TS
⇄
Reverse
TS → Text
Description model — The default series-to-text model is ChatTS-14B (bytedance-research, Apache-2.0). It runs in 8-bit on a separate GPU-shared server, loads on demand and unloads after 5 idle minutes; a cold request takes about 2 minutes and a warm one about 20 seconds. The model writes the narrative, while trend, volatility and feature numbers come from app-side computation to prevent hallucinated numbers. An external LLM can also be selected as the description model.

Eight representative pattern search scenarios.

1Natural Language Pattern Search (Text → TS)
Solar O&M Engineer
"Yesterday afternoon the power generation graph suddenly dropped. I want to check whether a similar pattern occurred on any other day this year."
Text mode

Switch to Segment view, select Text mode and type "gradually rises then suddenly drops after noon". The rule pre-pass or the model produces a synthetic shape and compares it against all segments.

Both views · Zero-shot · Rule pre-pass + local/external LLM · Column metadata improves accuracy
2Sketch Shape Search
Researcher
"I want to draw the double-peak pattern I have in mind and find similar ones."
Sketch mode

Draw the shape freely on the canvas → normalize → find similar patterns by sliding window or segment comparison

Zero-shot · Intuitive · Both views
3Preset Shape Search
Process Quality Manager
"I want to know when bell-shaped normal patterns and sharp spike patterns each appear in our sensor data."
Preset mode

In Segment view, pick one of the 7 built-in shapes (rise, fall, flat, bell, v_shape, spike, dip) or a custom preset saved from a cluster centroid. The "Classify All" button categorizes all segments by all presets at once.

7 built-in + custom presets · Automatic full classification · Multi-column support
4Search by Actual Segment (QBE)
Equipment Diagnostics Researcher
"I want to check whether other segments look like this specific waveform from March 15th."
Select or Sample

Select (Continuous): drag on the chart → sliding window finds all similar occurrences
Sample (Segment): click a segment card → 1:1 segment comparison

Actual data waveform as query · Most accurate · Euclidean/DTW/Cosine/Shape distance
5Multi-Column Search
Process Engineer
"I want to search across several sensors at once — temperature rising while power drops."
Preset mode · Multi-column

Search several columns (sensors) simultaneously. Distances are averaged equally across the selected columns, and in Preset mode each column can take a different preset (e.g. power=fall, temperature=rise).

Independent preset per column · Equal-weight averaging · Combined similarity · Compound pattern search
6Automatic Pattern Discovery (Clustering)
Data Analyst
"I don't know what patterns exist yet. I want to discover the natural groups in the data automatically."
Cluster mode

Choose Fast (K-Means), Shape (k-Shape) or Semantic AI (MOMENT) → segments are z-normalized and grouped automatically → per-column profiling → each cluster's centroid shape can be saved as a custom preset for reuse across datasets

Fast · Shape · Semantic AI · Auto-K · Save centroid as preset
7Cross-Column Pattern Correlation
Domain Expert
"When power output shows a bell curve, what do temperature or humidity typically look like? Are these correlations consistent?"
Cluster mode → Correlation map

After clustering, every column within each cluster is profiled automatically: the average shape and a consistency score (how uniformly members share the pattern). The Column Pattern Correlation map shows mini sparklines for all columns × all clusters, with consistency badges Strong, Moderate, Weak or Noisy.

All columns profiled · Cosine consistency metric · Primary/overlay tags · Sparkline visualization
8Segment Interpretation (TS → Text)
Operations Manager
"I want to know quickly whether this segment is normal or abnormal, and what each sensor's behavior looks like."
Describe

In Select mode, drag a region and click "Describe". ChatTS-14B (default) writes the shape narrative, while trend, volatility and feature numbers are filled from app-side computation. For multi-column data it gives per-column analysis plus an overall summary.

Single/multi-column · Shape, trend and volatility analysis · ChatTS-14B default (external LLM selectable) · Domain metadata aware
