데이터 관리 → 데이터 업로드 탭에서 CSV 파일 1개나 폴더를 올립니다. 폴더는 파일마다 소스로 두는 개별 모드와, 시간순으로 하나로 합치는 합치기 모드 중에서 고릅니다. 인코딩과 구분자는 자동으로 감지하며 직접 고칠 수도 있습니다.

같은 시각 겹침·AI 메타 추정·삭제 — 같은 시각이 두 번 이상 나오면 저장 안 함, 첫 값, 마지막 값, 평균, 밀기 중 하나로 처리합니다. 모든 시각이 똑같이 k번씩 나오면 지역별 파일 k개를 합친 것으로 진단해 알려 줍니다. 업로드 탭 맨 위 스위치를 켜면 외부 LLM(Anthropic Claude 또는 OpenAI 호환 서버, 관리자가 모델 연결 탭에서 연결)이 데이터셋 키·이름·설명·위치·시설·용량·측정 간격·특성·태그와 컬럼 메타를 채웁니다. 기본은 꺼져 있고 마지막 선택을 기억하며, AI가 채운 칸은 붉은 테두리로 표시되니 확인 후 저장합니다. 데이터 목록 탭에서 데이터셋을 지우면 연결된 전처리 결과·라벨·바스켓·프리셋·캐시·파일까지 함께 지워지고, 지우기 전에 DB 백업을 만듭니다. 공개 예시로 Elia(벨기에) 풍력 발전·예측 2015~2026 지역별 시간 CSV 5개, 상명풍력, 행원 기상탑 데이터가 data/wind_energy/에 있습니다.

사용 시나리오

데이터 준비 단계에서 자주 마주치는 실제 상황과 해결 방법입니다.

1데이터 형식 선택
연구원
"1년치 연속 데이터가 있는데, 모터 실행 기록처럼 여러 개의 짧은 CSV 파일로 된 데이터도 있습니다. 둘 다 분석할 수 있나요?"
두 가지 데이터 형식을 모두 지원합니다:
  • 연속 시계열: 하나의 긴 CSV 파일 — 슬라이딩 윈도우 검색, 시간 단위별 분할 가능
  • 세그먼트 컬렉션: 폴더 내 여러 CSV 파일 — 길이가 달라도 DTW로 비교 가능, 필요시 연결하여 연속 탐색
인코딩·구분자·인덱스 자동 감지 · 컬럼 메타(단위·최소·최대) 입력 또는 AI 추정 · 샘플링 간격 자동 계산
2품질 진단
데이터 분석가
"새로 받은 데이터인데, 어느 정도 결측값이 있는지, 이상값이 얼마나 심한지 먼저 파악하고 싶습니다."
데이터 품질 진단
전처리 전에 데이터 품질을 자동으로 진단합니다:
  • 샘플링 간격: 자동 감지 (1h, 15min, 1min 등)
  • 시간 갭: 센서 다운타임으로 인한 누락 구간 수 및 누락 포인트
  • 이상값 (IQR): 통계적으로 극단적인 값의 수량 및 비율
  • NaN 값: 결측값 수량 및 전체 대비 비율
읽기 전용 진단 · 원본 데이터 미변경 · 컬럼별 독립 분석
3데이터 전처리
데이터 엔지니어
"센서 갭과 이상치가 꽤 많아서, 원본 데이터로 바로 실행하면 신뢰할 수 없는 결과가 나올 것 같습니다."
전처리 파이프라인은 3단계로 실행됩니다:
  1. 극단값 처리: 값 범위 제한(컬럼 최소·최대) 또는 IQR/Percentile/Sigma 기반 이상치 클램핑 중 선택
  2. 시간 갭 채움: 센서 다운타임으로 누락된 타임스탬프를 NaN으로 삽입
  3. NaN 보간/복원: 8가지 방법 중 선택 — Linear, Cubic, Smoothing spline, Nearest, Zero fill, Forward fill, Adaptive, MOMENT(FM 기반 문맥 복원)
원본 보존 · 3단계 파이프라인 · 전/후 비교 차트 · 언제든 되돌리기
4FFT 주기성 분석
에너지 분석가
"태양광 발전 데이터인데, 일별로 분할하는 게 맞는지 주별이 나은지 잘 모르겠습니다. 데이터의 주기성을 먼저 확인하고 싶습니다."
FFT 주기성 분석
FFT(고속 푸리에 변환)를 사용하여 데이터의 숨겨진 주기성을 발견합니다:
  • 주 피크 감지: 가장 강한 주기적 패턴 자동 식별
  • 분할 단위 추천: 24h 피크 → 일별 분할 권장, 168h 피크 → 주별 분할 권장
  • 다중 주기 확인: 일별 + 주별 + 연간 패턴 동시 파악
스펙트럼 시각화 · 피크 자동 감지 · 분할 단위 추천
5시간 단위 분할
시설 관리자
"때로는 주 단위로, 때로는 시간 단위로 분석하고 싶습니다 — 목적에 따라 데이터를 다른 시간 단위로 분할해야 합니다."
시간 단위 선택 (6 types)
hour · 6hour · day · week · month · year 중 원하는 단위를 선택하면, 데이터의 샘플링 간격을 기반으로 세그먼트 길이가 자동으로 계산되어 분할됩니다.
  • 6시간: 오전/오후/저녁/야간 패턴 분리
  • 1일: 일별 프로파일 비교 — 태양광 발전 패턴에 이상적
  • 1주: 주간 추세 파악 — 평일/주말 패턴 구분
6가지 시간 단위 · 샘플링 간격 자동 감지 · 단위별 다른 패턴 · 즉시 전환
6세그먼트 연결 (Concat)
공정 엔지니어
"일별로 분할된 세그먼트 중 특정 3일을 선택해서 연결하고, 그 전체에서 패턴을 검색하고 싶습니다."
세그먼트 연결
여러 세그먼트를 선택하여 하나의 연속 데이터로 연결합니다:
  • 선택적 연결: 원하는 세그먼트만 골라서 연결
  • 슬라이딩 윈도우: 연결된 전체에서 패턴 검색 가능
  • 재분할: 연결 후 다른 시간 단위로 다시 분할 가능
멀티 선택 · 순서 유지 · 연결 후 재분할 · 전체 검색
