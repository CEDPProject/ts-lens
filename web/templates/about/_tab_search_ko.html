재사용 가능
생성 모델과 외부 LLM — Text 모드는 먼저 규칙 기반 선처리로 단순한 표현을 바로 파형으로 만들고, 나머지는 로컬 모델이나 외부 LLM(Anthropic Claude, OpenAI 호환)이 처리합니다. 사용자가 외부 LLM을 직접 고르면 규칙 선처리를 건너뜁니다. 외부 LLM은 관리자가 데이터 관리 → 모델 연결 탭에서 연결하며, API 키는 서버 파일에만 저장되고 화면에는 끝 4자리만 보입니다. 문장→파형·시계열→문장·AI 메타 추정 가운데 어디에 쓸지 고를 수 있고, 사용 토큰을 기록해 월 $10에서 경고하고 $100에서 막습니다(설정 가능).

각 세그먼트를 (값 - 평균) / 표준편차로 변환합니다. 절대 크기를 제거하고 곡선 형태만으로 비교합니다.
