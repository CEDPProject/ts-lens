Save Cluster Centroids as Custom Presets

After running Cluster analysis (Fast/Shape/Semantic AI), each cluster's centroid (Medoid — the actual member closest to center) can be saved to the Pattern Library as a custom preset. Saved shapes appear in Preset mode next to any built-in presets you have added, and are stored per-dataset for context relevance.

Workflow
  1. Switch to Segment view → run Cluster mode (Fast/Shape/Semantic AI)
  2. Review cluster results — each group shows its Medoid shape and member segments
  3. Click the button on a cluster card → name the pattern (e.g., "Morning Double Peak")
  4. The centroid is saved to the Pattern Library → available as a custom preset in Preset mode
  5. Delete custom presets via the × button (built-in presets cannot be deleted)
Benefits
Per-dataset storage: Presets are stored per-dataset — solar patterns appear only with solar data. The library lives on the server and is shared by all accounts
Medoid-based: Uses the actual member segment closest to center, not the mean — more robust to outliers
Iterative discovery: Cluster → save → search → refine → cluster again with more context

Cross-Column Correlation Insights

The Column Pattern Correlation Map generated during clustering shows how measured variables co-vary. Each cell holds an SVG sparkline of the actual average shape and a consistency badge indicating statistical reliability.

Consistency Levels
Strong (>=85%): Nearly all members share this shape — reliable pattern
Moderate (>=70%): Majority share the shape — generally reliable
Weak (>=55%): Some variance — interpret with caution
Noisy (<55%): High variance — the average shape is not representative

Real-world workflow examples using the labeling features.

1Building a Pattern Library
Data Analyst
"I want to select only the patterns I need from search results, save them to a pattern library, and reuse them later."
Labeling loop
  1. Search: Find patterns using Text/Preset/Sample/Cluster mode
  2. Evaluate: Accept accurate results, Reject incorrect ones
  3. Confirm: Review in Draft, then Confirm All to finalize
  4. Refine: Query improves from the average shape of confirmed segments
  5. Repeat: Re-search with the refined query → more accurate results → library grows
Iterate: search → select → save · Per-pattern instance management · Export labeling results (CSV)
2Creating Presets from Clusters
Researcher
"I want to save patterns discovered through clustering so I can quickly find the same patterns in new data later."
Custom presets
  1. Segment view → run Cluster mode (Fast/Shape/Semantic AI)
  2. Review cluster results — check each group's Medoid shape and member segments
  3. Click the button on a cluster card → name the pattern (e.g., "Morning Double Peak")
  4. Shown in purple in Preset mode for reuse
Per-dataset storage · Medoid-based (robust to outliers) · Cluster → save → search → refine iteration
3Classifying New Data
Operations Engineer
"I want to quickly classify new data arriving in the same dataset using the pattern library I built earlier."
Preset mode
  1. Load the new range of the same dataset → switch to Segment view
  2. In Preset mode, select a pattern saved in the library
  3. Click "Classify All" to classify every segment automatically
  4. Review the results and add labels where needed
Reuse saved patterns · Automated full classification · Export results
4Team Collaboration
Research Team Lead

Pattern Library

The pattern library is stored on the server per dataset and shared by all accounts. Patterns confirmed by team members accumulate in the library, and a new member who opens the same dataset can use the existing pattern definitions.
