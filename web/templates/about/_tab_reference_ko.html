기후 및 에너지 시계열 패턴

본 시스템에 등록되었거나 함께 제공되는 데이터셋에서 관측되는 대표적인 패턴입니다.

태양광 일사량 (GHI)

NREL Solar 2023 · 5분 간격 · nrel_solar_2023

clear_sky
맑은 날. 일출부터 일몰까지 부드러운 종 모양 곡선.
overcast
종일 흐림. 낮고 평평한 곡선.
intermittent
간헐적 구름. 들쭉날쭉한 반복적 변동.
dropout
구름대 통과. V자형 급락 후 회복.

풍력 터빈 출력

Elia(벨기에 TSO) 풍력 발전·예측 · 지역별 시간 CSV · data/wind_energy/

rated_wind
정격 풍속 구간. 최대 용량에서 안정적인 출력 유지.
ramp_up
점진적 풍속 증가. 출력이 꾸준히 상승.
calm
무풍 / 미풍. 풍속이 컷인 임계값 미만으로 출력 거의 0.

사용 시나리오

시나리오 1: 맑은 날 패턴 찾기 (Preset 모드)

  1. 패턴 탐색 메뉴에서 태양광 데이터셋을 엽니다
  2. "Segment View" → Time Unit "1day" → 365개 일별 세그먼트로 분할
  3. Preset 모드 → "bell" 프리셋 클릭 → "Search"
  4. → 168개 일이 종형 패턴과 유사한 것으로 발견

시나리오 2: 자연어로 복합 패턴 찾기 (Text 모드)

  1. Text 모드 → "아침에 빠르게 상승, 정오에 피크, 오후에 천천히 하강하는 비대칭 종형" 입력
  2. LLM이 해당 형태의 합성 시계열 생성 → 프리뷰로 확인
  3. "Search" → 34개의 비대칭 맑은 날 패턴 발견

시나리오 3: 군집화로 패턴 자동 발견 (Cluster 모드)

  1. Cluster 모드 → K-Means Auto-K → "Search"
  2. 시스템이 최적 K=5 선택 → 5개 클러스터 발견
  3. 맑음(142일), 부분흐림(98일), 흐림(76일), 급락(34일), 이상(15일)

주요 용어 설명

TS Pattern Finder에서 사용되는 핵심 개념과 용어입니다.

데이터 구조

용어설명
Single Dataset하나의 연속 시계열 데이터. Continuous 뷰에서 슬라이딩 윈도우 검색 가능.
Collection Dataset동일 구조의 세그먼트 모음. Segment 뷰에서 카드로 표시 및 1:1 비교.
Segment특정 시간 범위의 시계열 조각. 일별/주별 등으로 분할된 개별 단위.

검색 & 비교

용어설명
Query검색 기준이 되는 패턴. Select/Sketch/Sample/Preset/Text/Cluster 모드로 생성.
Sliding Window연속 데이터에서 고정 길이 윈도우를 이동하며 모든 위치에서 유사도 비교.
QBE (Query-by-Example)예시로 검색. 세그먼트 카드를 클릭하여 해당 파형을 쿼리로 사용.
Euclidean Distance각 포인트 간 거리의 제곱 평균의 제곱근 (RMSD).
DTW시간축 왜곡을 허용하는 유사도 측정. 길이가 다르거나 shift된 패턴도 비교 가능.
Z-score평균 0, 표준편차 1로 정규화. 형태만 비교, 절대값 차이는 무시.

군집화 & 분석

용어설명
K-Means (Fast)거리 기반 군집화. 빠르고 확장성 좋음, 범용 사용.
k-Shape (Shape)Shape-Based Distance(SBD) 사용. 스케일/시프트 불변, 시계열 전용.
MOMENT (Semantic AI)파운데이션 모델 기반. 다변량 Joint 클러스터링에 최적화.
Centroid (Medoid)클러스터 중심. 평균이 아닌 중심에 가장 가까운 실제 멤버.

LLM & 패턴 생성

용어설명
NL-to-Shape (DGS)자연어 → 규칙 선처리 또는 LLM(로컬/외부) → 합성 시계열 형태. Describe-Generate-Search 파이프라인.
Shape-to-Text세그먼트 → ChatTS-14B(또는 외부 LLM) 서술 + 앱 계산 숫자 → 자연어 설명.
Domain-Aware컬럼 메타데이터(단위, 범위)를 활용하여 물리적으로 타당한 형태 생성.

UI & 모드

용어설명
Continuous View연속 시계열 뷰. Select, Sketch, Text 모드 사용 가능.
Segment View세그먼트 뷰. Sample/Sketch/Preset/Cluster/Text 모드 사용 가능.
View-Adaptive데이터 뷰에 따라 사용 가능한 기능이 자동으로 조정됨.
Label Basket검색 결과에서 수락된 세그먼트를 수집. Draft와 Confirmed 단계.
